# Product Plan

## Vision

A standalone AR-first scorekeeping app for VEX Override that runs directly on Beam Pro and minimizes external dependencies.

## MVP

- start a match with team and ruleset selection
- track score and penalties in real time
- display timer, live score, and event log
- save match state locally
- export completed match data

## Non-Goals for v1

- fully automatic vision-based scoring
- mandatory cloud sync
- multi-user real-time collaboration

## System Areas

- scoring engine
- rules abstraction
- AR/touch UI
- local persistence
- export pipeline
